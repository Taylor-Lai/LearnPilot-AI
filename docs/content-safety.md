# 内容安全与防幻觉说明

LearnPilot AI 将学生输入、课程文档、检索片段和模型输出一律视为不可信内容。安全链路同时部署在主后端和 ML 服务，在线模型不可用时仍执行同一套本地规则。

## 防护流程

1. **输入清洗**：识别中英文提示注入，脱敏手机号、邮箱、证件号、API Key 和访问令牌。
2. **策略拒答**：危险操作指导与代考、代写等学术不端请求在调用在线模型前直接拒绝，并引导为安全、合规的学习问题。
3. **证据约束**：生成内容只能引用本次检索返回的 `chunk_id`；不存在或越界的引用会被移除。
4. **生成审核**：审核 Agent 检查知识点覆盖、练习与答案、易错点、个性化、多形态完整性、隐私、安全和引用一致性；失败内容自动修复并再次审核。
5. **输出清洗**：模型输出再次执行隐私、密钥和注入规则，避免模型复述不可信内容。
6. **可追踪性**：资源保留检索证据、合法引用、质量分、安全元数据以及生成—审核—修复轨迹。

## 自动化验收

`ml/data/benchmarks/safety-cases.json` 包含正常问答、提示注入、隐私、密钥、危险操作和学术不端案例。`learnpilot-ml-evaluate` 报告以下指标：

- 安全类别检测率、拒答准确率和敏感文本移除率；
- 合法引用完整率和有据生成率；
- “知识点覆盖 + 合法引用”的事实一致性代理指标；
- 生成审核通过率和安全生成率。

事实一致性代理指标不能等同于专家事实核验。正式提交前应由课程教师对固定抽样集复核概念、公式、代码结果和引用原文；报告中不得将自动指标表述为“零幻觉”保证。在线模型返回无可靠课程证据时，系统须明确提示证据不足并使用模板降级。

## 数据与日志边界

- 密钥仅通过环境变量注入，不写入仓库、数据库或前端包。
- 运行日志不得记录 Authorization、完整模型请求或未脱敏学生隐私。
- 评测答案由后端判分，前端不下发标准答案。
- 管理接口、任务结果和导出文件执行身份与所有者校验。
