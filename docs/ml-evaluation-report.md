# 推荐模型与生成质量评估报告

本报告由固定随机种子 `20260605` 的可复现实验生成。合成集包含 108 个知识点、540 个资源、1000 名学生和 6000 条行为事件；训练样本在构造特征时排除目标事件，并按学生分组划分训练/验证集，避免同一学生跨集合和标签泄漏。

## 排序模型训练

| 指标 | 结果 |
| --- | ---: |
| 可用标注样本 | 3289 |
| 训练样本 | 2645 |
| 按学生隔离的验证样本 | 644 |
| 验证 Accuracy | 0.9938 |
| 验证 AUC | 0.9985 |
| 训练/验证 AUC 差值 | 0.0015 |
| 数据指纹 | `3abed39aefd0cd76` |

线上排序采用 `10% LightGBM + 90% 可解释规则`。原因是当前训练行为为合成数据：模型可以提供反馈特征与非线性关系，但在获得真实匿名行为数据前，不应压过可解释的薄弱点、难度、偏好和质量规则。

## 小型人工可审查基准

| 指标 | 训练模型与规则融合 | 随机基线 |
| --- | ---: | ---: |
| Recall@5 | 1.0000 | 0.6250 |
| NDCG@5 | 0.8551 | 0.5410 |
| MAP@5 | 0.7815 | - |
| MRR@5 | 0.7778 | - |

该基准仅含 3 个可人工复核案例，适合回归检查，不足以证明真实教学场景泛化能力。融合排序在该基准上与纯规则 NDCG 相同，因此项目不会宣称“训练模型显著优于规则”。

## 消融实验

| 配置 | Recall@5 | NDCG@5 | MAP@5 | MRR@5 |
| --- | ---: | ---: | ---: | ---: |
| 完整融合排序 | 1.0000 | 0.8551 | 0.7815 | 0.7778 |
| 纯规则基线 | 1.0000 | 0.8551 | 0.7815 | 0.7778 |
| 移除资源偏好 | 0.7778 | 0.6273 | 0.4926 | 0.6111 |
| 移除掌握度差异 | 0.1111 | 0.0987 | 0.0556 | 0.1667 |

结果说明掌握度/薄弱点是排序的主要有效信号，资源形式偏好提供次要但明显的排序增益。模型融合未损害人工基准表现；真实数据到位后应重新搜索融合权重并冻结独立测试集。
