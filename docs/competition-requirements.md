# A3 赛题要求与验收矩阵

本文依据第十五届“中国软件杯”A3 赛题《基于大模型的个性化资源生成与学习多智能体系统开发》原文建立，是全项目开发、测试和答辩验收的唯一需求基线。

状态定义：

- **已完成**：存在完整用户入口、持久化、自动化测试和可演示证据。
- **部分完成**：主流程可用，但仍缺少正式产物、真实服务验证或充分测试。
- **未完成**：尚未形成可验收能力。

## 评分导向

实施优先级按评分权重排序：

1. **功能实现及技术要求（45%）**：完整课程、真实多智能体证据、正式多模态产物、动态闭环、稳定性。
2. **创新价值与实用性（35%）**：动态认知诊断、可解释推荐、证据约束生成、反馈驱动自适应和真实实验数据。
3. **配套文档（10%）**：需求、设计、开发、部署、测试、数据模型、开源合规和 AI Coding 说明。
4. **演示视频与 PPT（10%）**：围绕一个学生案例呈现画像、路径、资源、辅导、测评和自动调整全过程。

## 最终验收场景

使用一个人工智能课程学生案例，在全新环境中完成注册登录、自然语言画像、路径生成、个性化资源推送、多智能体生成至少 5 类正式产物、智能辅导、学习测评、画像更新、路径调整和管理端审计。全过程不得依赖预先写入的运行数据库，关键产物需可下载，生成内容需包含可靠课程依据、安全状态和可追踪的 Agent 执行记录。
